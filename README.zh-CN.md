# ComposeLib

一个面向 Jetpack Compose 的组件仓库，目标是同时提供：

- 可发布的 Compose 组件库；
- 用于本地预览和验收的 Android Demo App；
- 后续可扩展的 Web 预览站点；
- 统一的组件分类与元数据目录。

## 当前状态

仓库已完成设计与协作约定，正在按模块化组件仓的方向推进。
目前重点是先建立清晰的模块边界和组件目录，再逐步补充具体组件实现。

## 目标能力

1. **组件复用**
   - 通过 Maven 等方式供其他仓库依赖。
   - 提供基础组件与高级组合组件。

2. **在线预览**
   - 用 Android Demo App 预览全部组件。
   - 后续补充 Web 预览页。

3. **统一分类**
   - 组件按使用场景分类。
   - 同一套分类同时服务于 Demo App、Web 预览和文档。

## 规划中的模块

| 模块 | 作用 |
|---|---|
| `ui-components` | 可发布的 Compose 组件库 |
| `preview-app` | Android 预览与验证 App |
| `component-registry` | 组件目录与元数据 |
| `preview-web` | 浏览器端预览站点 |

## 指导文件约定

每个模块都维护协作指导文件：

- `CLAUDE.md`
- `AGENTS.md`

根目录文件定义项目级约定，子模块目录文件定义模块级约定。

## 开发原则

- 组件实现和预览展示分离。
- 组件目录是单一事实来源。
- 发布代码只放在可发布模块中。
- 预览、文档和目录元数据保持同步更新。
- 不自动提交代码；提交由用户手动完成。

## 后续计划

仓库后续会按以下顺序推进：

1. 建立多模块工程脚手架；
2. 接入可发布的 Compose 组件库模块；
3. 接入 Android 预览 App；
4. 补齐组件目录与分类；
5. 再扩展 Web 预览站点。
